How to use neoaudioscope

neoaudioscope is a measurement tool. It shows what is in the signal, not an art piece.

Load a signal

Push Open file and select an audio or a video file, or drag the file onto the window. For a video file, neoaudioscope uses the audio track only. Push ● in to analyse the microphone or the line input. The output stays muted for live input, to prevent feedback.

Arrange the panels

Each panel has a menu at the top left. Use it to change the display. The buttons at the top right do these functions:

Button 1
Show the options for this panel
Button 2
Split the panel from left to right
Button 3
Split the panel from top to bottom
Button 4
Make the panel full size, or return it
Button 5
Close the panel

Drag a line between two panels to change the sizes. Double-click that line to make the two panels equal.

The displays

Spectrum
The level at each frequency. Move the pointer on the graph to read a value.
Spectrogram
The spectrum against time. Colour shows the level.
Third octave
31 standard bands, as on a hardware analyser.
Oscilloscope
The waveform. The trigger keeps the image stable.
Stereo field
A goniometer. A vertical trace is mono. A horizontal trace is out of phase.
Phase & balance
Correlation, left/right balance and stereo width, with a history strip.
Levels
Peak and RMS for each channel, with peak hold and a clip indicator.
Loudness
Momentary, short term and integrated loudness, plus the loudness range.
Readout
Numeric values: peak frequency, musical note, centroid, crest factor and more.

Accuracy

The loudness values use a K-weighting filter to the ITU-R BS.1770 method. The peak value is a sample peak. There is no 4× oversampling, so a true peak can be higher than the value shown. Use these numbers for comparison, not for a final compliance report.
